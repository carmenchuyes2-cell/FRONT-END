# FRONT-END
Interfaz web (index.html y diseno.js) para los dos tipos de usuario. El cliente se registra o inicia sesión, arma su pedido con subtotal, IGV y total, y paga con efectivo, Yape o tarjeta. El cajero cobra o anula pedidos y genera la boleta. El administrador, además, consulta el reporte de ventas con filtros por método de pago y fecha.
